## Default Permission

Allows the main window to drive native Android playback.

#### This default permission set includes the following:

- `allow-subscribe`
- `allow-configure`
- `allow-set-queue`
- `allow-play`
- `allow-pause`
- `allow-seek-to`
- `allow-skip-to`
- `allow-set-volume`
- `allow-set-repeat-mode`
- `allow-set-spectrum-enabled`
- `allow-stop`
